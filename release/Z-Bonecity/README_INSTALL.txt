BONELAB Advanced Health System
Version: 1.0.0
Build date: 2026-05-22
Type: MelonLoader DLL mod

INSTALLATION
1. Install MelonLoader for BONELAB.
2. Install BoneLib. This package does not include BoneLib.
3. Extract this archive into the BONELAB game folder.
4. Confirm the DLL is located at:
   BONELAB/Mods/BonelabAdvancedHealth.dll
5. Start BONELAB.
6. Open BoneMenu and go to:
   Advanced Health System

DEPENDENCIES
- BONELAB on PC
- MelonLoader 0.7.x or newer
- BoneLib 3.x

MAIN FEATURES
- Tarkov-style body health monitor.
- BoneMenu health interface with realtime vitals, limbs, organs, bleeding, fractures and debug status.
- Fullscreen pain FX with blood pulse, tunnel vision, double vision, chromatic split, blur veil and focus loss.
- Advanced pain, bleeding, organ, bone, fracture, lung and head trauma systems.
- Head trauma and concussion logic with ringing, disorientation and delayed collapse.
- Knife penetration backend with embedded wound state and bleeding spike on removal.
- Native-first blood FX discovery with pooled fallback spray and round blood pools.
- Persistent config through MelonPreferences.

OPTIONAL AUDIO
The mod can load local WAV trauma tracks from:
BONELAB/UserData/BonelabAdvancedHealth/Audio

Supported file names:
- zcity_unconscious.wav
- zcity_pain.wav
- zcity_headhit.wav

Audio tracks are not included in this package. Only upload or redistribute audio that you own or have permission to use.

MOD.IO NOTE
