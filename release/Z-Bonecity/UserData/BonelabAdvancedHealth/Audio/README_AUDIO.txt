Audio folder for ZBoneCity.

The mod loads packaged sounds from BONELAB\ZBoneCity\Audio and also checks this legacy UserData folder.
Supported custom files:

- Headshot.wav
- Dead.wav
- MetalShot.wav
- zcity_unconscious.wav
- zcity_pain.wav
- zcity_headhit.wav

If a file is missing, ZBoneCity logs a warning and continues loading the game.
Only upload or redistribute audio that you own or have permission to use.
