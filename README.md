# Bonelab Advanced Health

Production-oriented MelonLoader DLL mod for BONELAB that adds a Z-City-inspired advanced health simulation:

- limb HP for head, torso, arms, and legs
- stackable light, medium, severe, and arterial bleeding
- blood volume, blood-loss death, blackout, unconsciousness, and recovery
- fracture penalties for legs, arms, and torso/ribs
- damage profiles for bullet, blunt, explosion, stab, and fall damage
- runtime medical items: bandage, tourniquet, morphine, medkit
- NPC bleeding, unconsciousness reactions, and blood-loss death
- minimal VR world-space HUD with blood, pulse, limb state, fractures, and pain

## Architecture

The mod is split into a pure gameplay health core and thin BONELAB adapters.

`HealthManager` owns all systems for one actor. Player and NPCs use the same model; `NPCHealth` only adds the BONELAB enemy adapter.

`DamageProcessor` converts real Marrow attacks and BONELAB collision callbacks into normalized `DamageInfo` values. Harmony patches hook:

- `Il2CppSLZ.Marrow.PlayerDamageReceiver.ReceiveAttack`
- `Il2CppSLZ.Marrow.PlayerDamageReceiver.OnCollisionEnter`
- `Il2CppSLZ.Bonelab.EnemyDamageReceiver.ReceiveAttack`
- `Il2CppSLZ.Bonelab.Enemy_Health.OnReceivedCollison`
- player/NPC reset paths

`BleedingSystem`, `ConsciousnessSystem`, and `FractureSystem` are timer-driven from `MainMod.OnUpdate` using configurable tick intervals. They do not allocate per frame in their hot paths.

Runtime medical items are generated by the DLL as Unity primitives with Rigidbody plus Marrow `MarrowEntity`, `MarrowBody`, and `BoxGrip` components when available.

## Install

1. Install MelonLoader for BONELAB.
2. Build this project in Release.
3. Confirm the DLL exists in `BONELAB\Mods`.
4. Start BONELAB.
5. MelonLoader should print `Bonelab Advanced Health` during startup.

## Runtime Use

Medical items spawn in front of the player after scene initialization. Bring an item close to the head/chest area for about half a second to apply it:

- Bandage: stops non-arterial bleeding on the worst bleeding limb, reduces pain, heals that limb slightly.
- Tourniquet: heavily controls bleeding on the worst bleeding limb, including arterial bleeding.
- Morphine: strongly reduces pain and temporarily dampens future pain.
- Medkit: restores blood, heals limbs, stabilizes fractures, and stops light/medium bleeding.

Settings are written to:

```text
BONELAB\UserData\MelonPreferences.cfg
```
